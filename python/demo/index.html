How to read this
  • Both runs use the same big model and the same prompt. The race replays them at the speed they were measured on your GPU.
  • Every round ends with exactly one yellow token, so yellow tokens = big-model passes. Green tokens cost only a cheap draft pass.
  • At temperature 0 the two texts must be identical — speculative decoding changes the speed, never the words. Above 0 both are random samples from the same distribution, so they can differ.
  • Very short outputs (one short sentence) and prompts the draft finds hard can be slower: there is a fixed start-up cost and wasted guesses. Long, ordinary text shows the real speedup — the full benchmark measured 1.7–1.9× on GPT-2 large.
